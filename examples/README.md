# Examples

Worked examples will be added as the MVP is trialled:

- `greenfield-sample/` — new "Leave request" feature: `/qa-init` on a near-empty repo
  (docs-led domain from the PRD) → `/qa-start` → G1 → G2 → G3.
- `brownfield-sample/` — existing HR app without written requirements: evidence-led domain
  discovery, targeted interview, DCP flow, regression selection.
- `aidlc-companion-sample/` — project with `aidlc-docs/`: domain seeded from AI-DLC reverse
  engineering, intake keyed by unit.

The domain templates in `../templates/domain/` already use the "Leave request" example
consistently (BR-012, J-04, ENT-leave-request) as a reference.
