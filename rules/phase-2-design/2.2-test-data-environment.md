**Agent:** `test-designer`. **Output:** `2-design/test-data.md`.

## Steps
1. For each TC list data needs (entities in specific states, roles/accounts, volumes).
2. Group into **data sets** `DS-01..` with: purpose, creation method (seed script / API /

   integration stubs/sandboxes, configuration differences.
5. Raise gaps not already in gap-analysis (append `GAP-xx`).
