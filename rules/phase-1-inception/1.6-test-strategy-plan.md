# Stage 1.6 — Test Strategy & Plan

**Goal:** an agreed, right-sized plan for testing this work item.
**Agent:** `risk-gap-analyst`. **Output:** `1-inception/test-plan.md`.
**Standard tier:** one-page plan (sections marked ★ only). **Comprehensive:** all sections.

## Sections (`templates/test-plan.md`)
1. ★ Scope — in scope (AC, features), out of scope (with reason)
2. ★ Approach — test levels (unit/API/UI/contract) and types (functional, negative,
   boundary, regression, exploratory, NFR) mapped to risks
3. ★ Regression scope — selected from 1.4
4. Environments & test data — from gap analysis; needs and owners
5. Tools — frameworks, platform test plan location
6. ★ Entry criteria — default from quality-standards, adjusted
7. ★ Exit criteria — **quantified**
8. Roles & responsibilities
9. Schedule / milestones (if known)
10. ★ Risks to the testing itself (env availability, data, dependencies) & contingencies
11. Gaps accepted (from 1.5)

## Self-check
- [ ] Every high risk mapped to an approach item
- [ ] Exit criteria measurable
- [ ] Out-of-scope items justified
