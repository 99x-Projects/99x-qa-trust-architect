# Stage 3.5 — Test Summary Report

**Goal:** give the G4 approver an honest, evidence-backed picture and a recommendation.
**Agent:** `execution-analyst`.
**Output:** `ITEM_DIR/3-execution/test-summary-report.md` (template `templates/test-summary-report.md`).

## Inputs
`execution-log.md`, `runs/*.yaml`, `defect-log.md`, `defects/*.yaml`, `regression.md`,
`1-inception/test-plan.md` §7 exit criteria (light tier or missing → `_project/quality-standards.md`
default exit criteria), `risk-assessment.md`, `test-case-index.md`, `qa-state.md` gate table,
`3-execution/sessions/*` (if 3.2b ran), `questions.md`, pending DCPs raised by this item.

## Steps
1. **Refresh** defect states from the platform first (3.3 §6) if enabled.
2. **Exit criteria:** evaluate every criterion with numbers computed from runs (latest result per
   TC / test). Never round a miss into a pass (97.6% ≠ ≥ 98%).
3. **Execution & defects tables** from runs and defects. Deferred TCs need a reason and who agreed.
4. **Coverage:** observability checks `OBS-xx` passed/failed/not run (failed or not run → residual
   risk); AC with ≥ 1 *passed* TC (latest run); high risks with passed mitigation tests;
   provisional-basis TCs and the questions they produced.
5. **Gate history:** every gate decision on the item, highlighting `overridden`,
   `approved-with-risks` and `stale`.
6. **Residual risks:** open/accepted defects, uncovered AC, failed exit criteria, untested
   adjacent areas, open blocking questions — each with a mitigation (often a 2.4 signal) and owner.
7. **Recommendation:**
   - `GO` — all exit criteria met, no open Sev1/Sev2, no untriaged failures
   - `GO with risks` — misses are covered by accepted risks with owners
   - `NO-GO` — open Sev1, an unmet exit criterion without an accepted risk, or untriaged failures
   Explain in 2–4 sentences. The recommendation never decides G4.
